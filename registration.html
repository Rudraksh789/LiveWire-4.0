Registration

Each school can register one team per event, and a participant can take part in only one event. Read the basics below, then register when the button opens up.

Before you register

  • Participating schools register online through the official website.
  • Each school may register one team per event; a participant joins only one event.
  • Prelim entries are submitted only through the official submission page — no other channel.
  • All entries must be strictly original and follow the specific event's rules.
  • Files are named in the format schoolID_eventname.
  • Late submissions are not entertained, so build in buffer time.
  • Joining the official Discord server is required for updates and event-head contact.
